منصة آلين 4.1.5 — تعديل مسارات تتبع الطلب

- المصدر: النسخة الأصلية 4.1.5.
- زر التتبع موجود في الشريط العلوي بجانب الخيارات.
- نافذة التتبع معزولة عن CSS العام ولا تستخدم SVG.
- حذف اسم الطالب واسم المكتبة/المندوب وقيمة الطلب وعدد النسخ ورمز الاستلام من نافذة التتبع.
- إبقاء رقم الطلب والعنوان والحالة والتاريخ والملاحظات.
- مسار الملزمة: تم الاستلام ← قيد الطباعة ← جاهز ← تم التسليم.
- مسار المنتجات غير القابلة للطباعة: تم الاستلام ← قيد التجهيز ← جاهز ← تم التسليم.
- مسار المندوب: تم الاستلام ← تم تعيين المندوب ← في الطريق ← تم التسليم.
- إلغاء مرحلة قيد المراجعة من العرض.
- لا توجد تغييرات SQL أو تغييرات في بيانات Supabase.
