ALIN v4.0.0 Clean New Project

الحالة:
إعادة بناء نظيفة على مشروع Supabase جديد، وليست Migration أو Patch للقاعدة السابقة.

البنية:
- 35 جدولاً أساسياً.
- orders ثابت بـ69 عموداً بدلاً من جدول 99 عموداً المتراكم.
- ledger واحد بحالات مالية موحدة.
- settlements واحد.
- خدمة واحدة لتأكيد الطلب ومنع التكرار وحجز المخزون.
- خدمة واحدة لتغيير الحالة والتسليم والحسابات الذرية.
- عرض عام آمن للملازم بدون مسار PDF.
- عرض خاص للمكتبة لا يكشف PDF إلا عند وجود طلب فعلي.
- RLS للأدوار وحماية وظائف RPC الداخلية.
- تخزين عام للصور وتخزين خاص لـPDF وDOCX.
- تسجيل دخول وحارس محاولات وBootstrap لأول مدير.

الفحص المحلي:
- تركيب 81 ملف JavaScript.
- تحليل 8 ملفات TypeScript لوظائف Edge.
- فحص روابط HTML والملفات المحلية.
- 53 فحصاً ثابتاً للبنية والأمان ومسارات الطلب والمال.
- اختبارات حسابية للاستلام من المكتبة والتوصيل.

الحد الصريح:
لم يتم تشغيل SQL على مشروع Supabase حي من بيئة البناء. يجب تنفيذ النسخة على مشروع جديد تجريبي ثم اختبار دورة الطلب كاملة قبل نقل البيانات أو استبدال الموقع الحالي.
