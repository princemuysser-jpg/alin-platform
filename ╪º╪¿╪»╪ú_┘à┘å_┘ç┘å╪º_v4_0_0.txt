مهم جداً:
هذه النسخة ليست ترقيعاً ولا تحديثاً لقاعدة البيانات القديمة.
لا تنفذ SQL على مشروعك الحالي. أنشئ مشروع Supabase جديداً ورابط اختبار منفصلاً.

الملفات الرئيسية:
1) ALIN_V4_CLEAN_PROJECT_MASTER.sql
   ملف SQL الوحيد. ينشئ قاعدة جديدة كاملة ويتوقف قبل أي تعديل إذا وجد جداول آلين قديمة.

2) دليل_التثبيت_الكامل_v4.md
   خطوات الإنشاء والنشر والاختبار بالتسلسل.

3) نشر_Edge_Functions_Windows.ps1
   ينشر وظائف الدخول وإدارة الحسابات على المشروع الجديد.

4) setup-new-project.html
   ينشئ أول مدير ويولد ملف alin-config.js.

5) alin-config.js
   ضع داخله Project URL وAnon Key للمشروع الجديد فقط.

المسار الصحيح:
مشروع Supabase جديد ← SQL واحد ← Edge Functions ← رابط اختبار منفصل ← إنشاء المدير ← اختبار كامل.

لا تنقل من القاعدة القديمة:
orders أو ledger أو التسويات أو طلبات الاختبار.

بعد نجاح الاختبار فقط تنقل:
الحسابات الحقيقية، الملازم، المنتجات، المكتبات، المندوبين، المناطق، والإعدادات.
